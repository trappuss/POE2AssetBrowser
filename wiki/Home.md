# POE2AssetBrowser

> ⚠️ **Extremely early version (v0.9.0, alpha).** A preview, not a finished tool — expect rough edges
> and gaps it names honestly. The version number is historical; read it as "early preview".

[The tabs](The-tabs). The measured format reference is [Asset formats](Asset-formats) (and the
fuller `docs/FORMATS.md` in the repo).
